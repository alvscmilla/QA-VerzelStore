# Verzel Store — QA Testing

Projeto desenvolvido como parte de um processo seletivo para QA Jr, com o objetivo de analisar e validar a aplicação **Verzel Store** após a implementação das funcionalidades de **cupom de desconto** e **frete grátis**.

## Objetivo

Realizar testes manuais, exploratórios e automatizados, identificando possíveis comportamentos inesperados e documentando os resultados encontrados.

## Escopo

* Levantamento de cenários de teste a partir da documentação;
* Testes manuais;
* Testes exploratórios;
* Registro dos resultados de cada cenário;
* Identificação e documentação de bugs;
* Registro de evidências;
* Automação de pelo menos 3 cenários utilizando Playwright.

## Estrutura do projeto

| Diretório/Arquivo    | Descrição                                             |
| -------------------- | ----------------------------------------------------- |
| `cenarios-de-teste/` | Cenários de teste levantados a partir da documentação |
| `execucao/`          | Resultados dos testes manuais e exploratórios         |
| `bugs/`              | Relatórios dos bugs encontrados                       |
| `evidencias/`        | Evidências dos testes realizados                      |
| `automacao/`         | Testes automatizados utilizando Playwright            |
